# NiASPIRE Website

Official website of NiASPIRE — Niagara Youth Achievement & Opportunity Initiative.

NiASPIRE stands for Niagara Achievement, Skills, Prevention, Incentives, Resilience & Empowerment.

Slogan: Learn. Earn. Lead.

Co-Founders: Anthony Adeoye and Dunsin Fakorede.

This repository holds the static homepage (index.html). It will be published with GitHub Pages for internal sharing.
